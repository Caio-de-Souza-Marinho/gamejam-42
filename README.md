## 📖 Sobre o jogo

**Glitch Dungeon** é um *2D Shooter* onde o jogador enfrenta ondas de inimigos em masmorras geradas dinamicamente, evoluindo suas habilidades através de upgrades conforme avança.

- 🎮 **Estilo:** 2D Shooter
- 🛠️ **Mecânicas principais:** Ataque, Upgrades
- ⚙️ **Engine:** Godot

## ✨ Pontos-chave

- 🗺️ **Geração dinâmica de mapa** — cada partida apresenta uma masmorra diferente
- 📈 **Progressão de dificuldade** — o desafio aumenta conforme o jogador avança
